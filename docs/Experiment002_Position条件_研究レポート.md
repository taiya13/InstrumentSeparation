# Experiment 002 — Position（空間情報）条件による同一楽器分離の検証

**位置づけ**: 独自研究の Experiment 002。Experiment 001（Score 条件）と**直接比較できる条件**を維持し、**Score を一切使わず Position のみ**で同一音色ヴァイオリン（第1/第2）の分離がどこまで改善するかを検証する。
**日付**: 2026-07 / **ステータス**: 実装・実験完了（CPU, torch 不要）
**方針**: 条件を増やさず、**Position 単独の効果**を明確に評価する。

---

## 0. エグゼクティブサマリー

- **仮説は支持された**。同一音色2ヴァイオリンで、**Position（ステレオの channel 間レベル差 ILD）のみ**を条件にすると、音声のみ（モノ）比で **SI-SDR +10.25 dB / SIR +12.6 dB**（pan ±0.3）改善し、モノ・オラクル上限（11.1 dB）にほぼ到達。
- **ただし効果は空間分離量に強く依存**（pan ±0.1 で +1.5 dB、±0.3 で +10.2 dB、±0.5 で +11.6 dB）。**近接配置（同一位置に近い）では Position はほぼ無力**。
- **Score（Exp 001, +6.99 dB）との本質的違い**: Score は「**同音高（ユニゾン）で失敗**、位置に非依存」、Position は「**同一位置で失敗**、音高に非依存」。両者は**相補的**。
- 直接比較のため、**音源・テスト曲・SR/STFT・評価指標・音声のみ床は Exp 001 と完全一致**（baseline SI-SDR ≈ 0 も一致）。

---

## 1. Position の定義

| 問い | 内容 |
|---|---|
| **どの空間情報を使うか** | **channel 間レベル差（ILD, Interchannel Level Difference）**。各ヴァイオリンを異なる方位（pan）に配置した**ステレオ**混合が持つ左右チャネルのレベル比。 |
| **取得・表現** | 定電力パンニング（pan-pot ステレオ＝多くのオーケストラ・ステレオミックスの形式）で各音源を配置。Position 条件＝各ターゲットの**期待 channel 間 log レベル比** `ρ_i = log(gR_i/gL_i)`。観測は各 TF 点の `obs = log(|R|/|L|)`。 |
| **なぜ有効か** | ある TF 点で 1 音源が支配的なら、その点の channel 間比は**その音源の位置**を表す。**音色が同一でも「どこから鳴っているか」で振り分けられる**（WHAT ではなく WHERE を使う）。 |

> 本実験は ILD のみ（定電力パン）。実際のマイクアレイは ITD/IPD（時間/位相差）も持ち更に手がかりが増えるが、残響で劣化する（§6）。

---

## 2. 実験設計（Exp 001 と同一条件を維持）

| 項目 | 内容（Exp 001 との同一性） |
|---|---|
| **音源・テスト曲** | `gen_pool(seed=999)` の**同一 16 曲**（同一音色2ヴァイオリン、狭音域ランダムウォーク）。Exp 001 と**完全一致**。 |
| **SR/STFT** | 22.05 kHz, n_fft=1024, hop=256（Exp 001 と一致）。 |
| **唯一の変更** | 条件信号を **Score → Position** に置換。混合を**モノ→ステレオ**（各ヴァイオリンを pan 配置）。**Score は一切不使用**。 |
| **ベースライン** | 音声のみ床＝**モノ混合そのまま**（Exp 001 と同一）。 |
| **評価** | SI-SDR / SI-SDRi / SDR / SIR / SAR、Vln1/Vln2 別（Exp 001 と同一）。 |
| **primary 配置** | pan ±0.3（隣接だが弁別可能な現実的分離）。加えて ±0.1〜±0.8 の**感度掃引**（Position 単独の特性把握）。 |

## 3. 実装（Score を使わず Position のみ）

`src/run_exp002_position.py`（torch 不要・学習不要、Exp 001 の解析的検証と同型）:
- **Position 条件マスク**: `obs=log(|R|/|L|)`、`w_i = exp(-(obs-ρ_i)²/2σ²)`、`mask_i = w_i/Σ w_j`、`est_i = iSTFT(mask_i · MID)`（MID=(L+R)/2、SI-SDR はスケール不変）。
- Exp 001 の `gen_pool / stft / istft / score_method / separate` を**そのまま import**して条件・評価の一致を保証。
- **Score 由来の情報は一切参照しない**（音符列は使わない）。

---

## 4. 評価結果（held-out 16 曲）

| 手法 | SI-SDR | SI-SDRi | SDR | SIR | SAR |
|---|---|---|---|---|---|
| 音声のみ（床, モノ） | −0.02 | 0.00 | 0.30 | 0.30 | (∞*) |
| **Position（pan ±0.3）** | **10.23** | **+10.25** | 11.25 | 12.90 | 16.65 |
| オラクル IRM（モノ上限） | 11.11 | +11.13 | 12.56 | 17.65 | 14.47 |

（*床はアーティファクト無しで SAR 発散＝無意味。）

**空間分離量への依存（感度掃引）**:

| pan 分離 | ±0.1 | ±0.2 | ±0.3 | ±0.5 | ±0.8 |
|---|---|---|---|---|---|
| SI-SDR | 1.46 | 5.61 | **10.23** | 11.63 | 10.99 |
| SIR | 1.79 | 6.25 | 12.90 | 18.80 | 18.73 |

- **近接（±0.1）ではほぼ無力**（+1.5 dB）＝位置がほぼ同じだと ILD 手がかりが消える。
- **十分離れると（±0.3〜0.5）オラクルに肉薄・超過**。±0.5 で SI-SDR 11.63 は**モノ・オラクル（11.11）を上回る**＝ステレオ2ch の情報がモノ・マスク上限を超えるため（重要）。
- Vln1/Vln2 とも同等改善（取り違えなし）。
- 出力: `results/exp002_position_results.json`。

## 5. Experiment 001 との比較

| 観点 | **Score 条件 (Exp 001)** | **Position 条件 (Exp 002)** |
|---|---|---|
| 主要結果 SI-SDRi | +6.99 dB | **+10.25 dB**（pan ±0.3） |
| 必要な入力 | 各ターゲットの**楽譜/音高** | **ステレオ/多ch** ＋ 各ターゲットの**位置** |
| 音源データ | **モノで可** | **空間収録/パンが必須** |
| 失敗する条件 | **ユニゾン（同音高）** | **同一位置（近接配置）** |
| 性能を決める要因 | 音高の重なり具合 | **空間（角度）分離** |
| 実録での入手性 | 楽譜＋アライメントが必要／**モノ市販音源でも効く** | 多ch収録が必要／**ステレオ市販ミックスは人工パン・ダウンミックスで信頼薄** |
| 長所 | モノで効く・位置非依存・クラシックは楽譜がある | 角度が離れれば非常に強力・**楽譜不要**・モノ上限を超えうる |
| 短所 | ユニゾンで無力・アライメント誤差 | 近接/モノ化で無力・残響で劣化 |

**要点**: 数値上は本設定で Position(+10.25) > Score(+6.99) だが、これは**配置に依存**する（pan ±0.1 なら Position は +1.5 で Score に大きく劣る）。両者は**直交する失敗モード**（同音高 vs 同位置）を持ち、**相補的**。

## 6. 考察

### 6.1 なぜ改善したか
- 音色が同一でも、**支配的 TF 点の channel 間比が音源の位置を一意に示す**ため、位置で振り分けられる。角度差が大きいほど支配点が明瞭になり分離が向上。
- ステレオ2chは**モノ・マスクの情報上限を超える**ため、十分な分離角では oracle(モノ)を上回りうる。

### 6.2 なぜ（条件により）改善しなかったか
- **近接配置（±0.1）**: 2音源の ILD がほぼ同一 → 観測比が両者を区別できず mask≈0.5 → 分離不能。これは Position の原理的限界（同位置＝同一位置の楽器は空間で分けられない）。
- **重なり TF 点**: 両音源が同程度に鳴る点では観測比が中間値になり曖昧。
- 本実験は**ILD のみ・残響なし**の理想条件。実録では残響が ILD を平滑化し、ステレオ・ダウンミックスやモノ配信では空間情報自体が失われる。

### 6.3 次に研究すべき課題
1. **Score ＋ Position 併用**（Experiment 003 候補）: 失敗モードが直交するため、**ユニゾンは Score、近接は Position** で補い合い、両条件で頑健化するはず。
2. **ITD/IPD・残響を含む現実的空間**（room IR 畳み込み、マイクアレイ）での劣化評価。
3. **実録ステレオ/多ch**（Cadenza 弦楽四重奏、Aalto）での検証。
4. ニューラル条件付け backbone に**位置埋め込み**を条件入力として統合し実規模学習。

### 6.4 結論
**「Position のみで同一楽器分離を改善できる」仮説は支持された**（SI-SDRi +10.25 dB @ pan ±0.3）。ただし効果は**空間分離量に強く依存**し、近接配置では無力。Score が「同音高で失敗・位置非依存」なのに対し Position は「同位置で失敗・音高非依存」で、**両者は相補的**。次は両者の併用でどちらの失敗モードも埋められるかを検証するのが自然。
