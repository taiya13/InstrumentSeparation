# Experiment 003 — Score ＋ Position 併用による同一楽器分離の検証

**位置づけ**: 独自研究 Experiment 003。Exp 001（Score）・Exp 002（Position）と**同一条件**で、4 条件（音声のみ / Score / Position / Score+Position）を比較し、**「Score と Position は本当に互いの弱点を補完するのか」**を最難条件（ユニゾン・近接・ユニゾン＋近接）で定量検証する。
**日付**: 2026-07 / **ステータス**: 実装・実験完了（CPU, torch 不要）
**方針**: 条件を増やさず、単一仮説を検証。

---

## 0. エグゼクティブサマリー

- **仮説は「部分的に」支持された**（重要な非自明の知見）。
- **併用（Score+Position）は、各シナリオで「良い方の単独手がかり」に一致し、常に単独以下にならない**。
- **Position の弱点（近接配置）は Score が補完**する（近接＋異音高で Position 0.44 → 併用 7.19 dB）。→ **位置軸では相補的**。
- **しかし Score の弱点（ユニゾン）は Position で補完できない**（ユニゾン＋離間配置で Score 0.20 / Position 0.64 / 併用 0.64＝**両方失敗**）。→ **音高軸では相補しない**。
- 理由: **Position（本実装の ILD マスキング）も Score と同様に「時間周波数（TF）の分離可能性」に依存**する。ユニゾンは両音源を同一 TF ビンに重ねるため、**マスキング系のどの手がかりでも分離できない**。
- **ユニゾン＋近接（最難）は全条件で失敗**（情報が存在しない）。
- 結論: **相補性は非対称・部分的**。Score+Position は単独より頑健（位置退化に強い）だが、**同一音色のユニゾンはマスキングの共通の壁**として残る。

---

## 1. 仮説（単一）

> **H1-003**: Score と Position を同時に条件入力すると、各単独手がかりの失敗モード（Score＝ユニゾン、Position＝近接配置）を相互補完し、併用は各シナリオで単独以上に頑健で、**両手がかりが同時に退化する場合（ユニゾンかつ近接）にのみ失敗する**。

---

## 2. 実験設計（Exp 001/002 と同一条件）

- **音源・SR/STFT・評価指標・合成法**は Exp 001/002 と一致（同一音色2ヴァイオリン、22.05kHz、n_fft=1024/hop=256、SI-SDR/SDR/SIR/SAR）。
- **4 条件を同一データで比較**: 音声のみ（baseline）/ Score 単独 / Position 単独 / Score+Position。
- **全手法が同一信号 `MID=(L+R)/2` をマスク**（差はマスクのみ＝厳密比較）。
- **最難条件を分離する 2×2 ストレステスト**（音高 × 位置）:

| シナリオ | 音高 | 位置 | 何を試すか |
|---|---|---|---|
| A | 異なる | 離間(±0.3) | 両手がかり有効（易しい） |
| **B** | **ユニゾン** | 離間(±0.3) | **Score の弱点** → Position が救えるか |
| **C** | 異なる | **近接(±0.05)** | **Position の弱点** → Score が救えるか |
| **D** | **ユニゾン** | **近接(±0.05)** | 両退化（最難） |

- **併用の方法**: 2 つのソフト割当重みの**乗算融合** `w_i = w_score_i · w_position_i`、`mask_i = w_i/Σ w_j`。片方が曖昧でも他方が支配 → 情報のある手がかりを自動採用。

## 5. 「Score と Position は互いの弱点を補完するのか」への回答

**部分的に Yes（非対称）**。

1. **併用は常に「良い方の単独手がかり」に一致**し、単独より劣化しない（A:≈Position, C:≈Score）。SIR では併用が両単独を上回る場面もある（A: 15.95 > 12.95）。
2. **Position の弱点＝近接配置は Score が補完する**（C: Position 0.44 → 併用 7.19）。→ **位置軸で相補的**。✓
3. **Score の弱点＝ユニゾンは Position では補完できない**（B: Score 0.20・Position 0.64・併用 0.64＝ともに失敗）。→ **音高軸では相補しない**。✗
4. **ユニゾン＋近接（D）は全条件で失敗**（情報が無い）。

→ 当初仮説「両者は相補的で、両退化時のみ失敗」は **B が反例**（離間していても、ユニゾンなら Position も失敗）。**相補性は位置軸のみで成立し、音高軸（ユニゾン）は両手がかりの共通の壁**であることが判明。

---

## 6. 考察

### 6.1 なぜ Position はユニゾンで失敗したか（最重要）
- **Position（本実装＝ILD per-bin マスキング）も、Score と同じく「1 音源が各 TF ビンを支配する（W-disjoint 性）」を前提**とする。
- ユニゾンでは両ヴァイオリンが**同一音高＝同一 TF ビン**を同時に埋めるため、どのビンも両者の混合 → 観測 channel 間比が中間値 → 振り分け不能。**離間配置でも救えない**。
- 従って **ユニゾンは「音色」だけでなく「TF 占有」も共有する**ため、マスキング系の**すべての手がかり（Score も Position も）に共通の失敗モード**。これは Phase 1 の「同一音色ユニゾンはオラクルでも不可能」と整合し、さらに**「Position でも（マスキングでは）不可能」**であることを新たに示した。

### 6.2 併用が単独以上に劣化しない理由
- 乗算融合は、片方の重みが曖昧（一様）なら他方が支配するため、**情報のある手がかりを自動選択**。だから A では Position、C では Score に一致し、単独ベストを下回らない。

### 6.3 重要な限界と次の方向（マスキングを超える）
- **決定系（2 音源・2 チャネル・瞬時パン）では、混合行列 `[[gL1,gL2],[gR1,gR2]]` が可逆なら線形逆行列（ビームフォーミング/ICA）で s1,s2 を厳密復元でき、ユニゾンでも分離可能**。すなわち「Position 情報」自体はユニゾンを解く力を持ちうるが、**本実験の per-bin マスキングはその力を使えていない**。
- ただし**実際のオーケストラは多音源をステレオ2chへ畳み込み的に混合する劣決定系**で、逆行列は使えず**マスキングに戻る** → 現実のダウンミックスではユニゾンは依然困難。
- 次段候補:
  1. **多チャネル・空間フィルタ（ビームフォーミング/空間共分散）＋ Score 事前分布**で、離間ユニゾンの厳密分離を狙う（本実験の per-bin マスキングの限界を超える）。
  2. **ITD/IPD（時間・位相差）や残響**を含む現実的空間での再評価。
  3. ユニゾンの根本対策として**相関分解・生成事前分布**（マスキングに依存しない）を検討。

### 6.4 結論
**Score と Position の相補性は「非対称・部分的」**である。併用は単独より頑健で、**Position の位置退化（近接）を Score が補う**が、**ユニゾン（同一音高）は Score・Position（マスキング）に共通の壁**として残り、Position でも補完できない。これは「同一楽器分離の最難所はユニゾンであり、それを越えるには per-bin マスキングを超えた空間フィルタや生成的手法が必要」という、次フェーズへの明確な指針を与える。
